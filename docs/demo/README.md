# Demo

Guardar aquí el guion, las instrucciones de preparación y las evidencias.

Secuencia sugerida:

1. Seleccionar una empresa y cargar pedimentos ficticios.
2. Mostrar materiales, saldos y fechas de vencimiento.
3. Registrar producción y consumo PEPS, si se implementa la extensión.
4. Registrar una exportación y comprobar el saldo actualizado.
5. Mostrar alertas a 90, 60 y 30 días y exposición estimada en MXN.
6. Consultar el historial de cambios.
7. Mostrar cierre, excepciones y reporte si están disponibles.

Usar los escenarios de `data/samples/`. Documentar cómo restablecer los datos antes de cada presentación.
