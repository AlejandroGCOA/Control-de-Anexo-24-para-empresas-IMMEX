# Datos de desarrollo

- `samples/`: datos ficticios para los tres perfiles del reto.
- `templates/`: formatos de carga para pedimentos, exportaciones, BOM, producción e inventario.

Documentar columnas, unidades, moneda, fechas y RFC ficticio en cada escenario. Incluir casos que activen alertas a 90, 60 y 30 días, material vencido y material exportado.

Los archivos reales de clientes no forman parte de estos ejemplos. `local/` está reservado para datos locales excluidos de Git.
