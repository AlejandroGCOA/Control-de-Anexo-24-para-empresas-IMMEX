# Control-de-Anexo-24-para-empresas-IMMEX
Plataforma inteligente para la gestión y control de Anexo 24 en empresas IMMEX. Centraliza pedimentos, inventarios, producción y exportaciones, automatiza descargas PEPS, monitorea vencimientos y exposición en MXN, y utiliza IA para detectar y explicar excepciones.

## Organización del repositorio

- `apps/web/`: interfaz y pantallas de la plataforma.
- `apps/api/`: módulos de negocio, integraciones y tareas programadas.
- `contracts/`: contratos de API y formatos de importación.
- `database/`: migraciones y datos iniciales.
- `data/`: plantillas y escenarios ficticios de prueba.
- `docs/`: arquitectura, alcance, demo y presentación.
- `tests/`: pruebas unitarias, de integración y de extremo a extremo.
- `infra/`: configuración de infraestructura y despliegue.
- `scripts/`: utilidades de desarrollo.

Consulta el [mapa completo de carpetas](docs/estructura.md) y el [alcance del reto](docs/negocio/alcance.md).

Esta base contiene la estructura organizativa; todavía no incluye una aplicación ejecutable ni fija un lenguaje o framework.
